{%- comment %} Canonical. Defaults to this page, which is what we want: this site is the original. `canonical_url` in a post's front matter overrides it, for the rare case where the true original genuinely lives somewhere else. NOTE: this tag cannot make this site win a duplicate-content contest on its own. Where a piece is also on Medium, the canonical that decides it must sit on MEDIUM pointing here - which Medium only adds via its "Import a story" flow.
