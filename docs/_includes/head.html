{%- comment %} Canonical. Defaults to this page, which is what we want: this site is the original. `canonical_url` in a post's front matter overrides it, for the rare case where the true original genuinely lives somewhere else. NOTE: this tag cannot make this site win a duplicate-content contest on its own. Where a piece is also on Medium, the canonical that decides it must sit on MEDIUM pointing here - which Medium only adds via its "Import a story" flow. See CLAUDE.md. {%- endcomment %} {% comment %} Social cards. Without og:image a shared link renders as a grey box in Messages, Slack and Facebook — which is most of how a book gets passed on. absolute_url, not relative_url: these have to be full URLs. {% endcomment %} {%- comment %} THE CARD IS THE POST'S OWN PICTURE when it has one (2026-09-22). Order: an explicit og_image, then the post's own photograph, then the trilogy card as the last resort.
