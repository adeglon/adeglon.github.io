{% comment %} LISTEN — a play button that reads the essay aloud. Some readers would rather listen than read, and these essays are long enough that people want them on a walk. This uses the voice already built into the reader's own device (the Web Speech API), so there are no audio files to make, to store, or to regenerate every time Agnès edits a sentence. It costs nothing and it works on all thirty-six essays the moment it ships. The honest trade: the voice is the device's, not hers. On an iPhone or a Mac it is a good one. On Windows it is noticeably more robotic. Nobody can download it and it will not appear in a podcast app. If those things start to matter, real recordings can replace this later, per essay, without the button moving. It renders HIDDEN and the script reveals it only after confirming the browser can actually speak — the same rule the chat button follows, so it can never be a button that does nothing. {% endcomment %}
