Only

content is prose. Short paragraphs (a one-line opener, a caption) are skipped so the teaser is not a fragment. Jekyll includes share the page's variable scope, which is how the value comes back out. {%- endcomment %} {%- assign _limit = include.limit | default: 300 %} {%- assign _chunks = include.post.content | split: '

' %} {%- assign _body = '' %} {%- for _chunk in _chunks %} {%- assign _para = _chunk | split: '
